# เดโมประมาณหนึ่งนาที

1. 0–10วินาที: เปิด http://localhost:5173 เห็นแผนที่ประเทศไทยและป้ายโครงการสมมติ เลือกจังหวัดเชียงใหม่ รายการเหลือ2โครงการ
2. 10–20วินาที: ค้นหา “ใบไม้วันใหม่” แล้วเลือกกลุ่มบริษัท แผนที่แสดงทั้งดอยสุเทพ แก่งกระจาน และดอยภูคาในคนละจังหวัด
3. 20–30วินาที: ค้นหา FP-001 เปิดรายละเอียด ดูพื้นที่ขอบเขตตัวอย่างแยกจากพื้นที่/คำกล่าวอ้างสมมติ เห็นกริด50mเลื่อน25m
4. 30–45วินาที: กดวิเคราะห์ช่วง2023-01-01ถึง2023-04-01เทียบ2025-01-01ถึง2025-04-01 ดู acquisition dates, NDVI, tree probability และประเภทหลักฐาน หากมีผลแคชจริงจะโหลดเร็ว หากยังไม่แคชให้รอกระบวนการจริงโดยไม่เติม progress สมมติ
5. 45–60วินาที: กด “เปรียบเทียบก่อน–หลัง” แผงตั้งค่าขวาจะพับเป็นภาพอีกช่วงเวลาในหน้าหลัก รายการโครงการซ้ายยังอยู่ ลองซูม/เลื่อนพร้อมกัน เปิด–ปิดสัญญาณต้นไม้และกริด กด “เปิดตั้งค่า” เพื่อดูวันที่และดาวน์โหลด JSON หรือ “แผนที่เดียว” เพื่อดู evidence/quality และรายละเอียดช่อง

เตรียมงานวิเคราะห์ FP-001 ให้เสร็จก่อนเดโม1นาที การประมวลผลสดอาจใช้เวลาหลายนาที และ map token ต้องโหลดใหม่เมื่อหมดอายุ หากไม่มีสิทธิ์ GEE แสดงข้อความไม่พร้อม แล้วเดโมการค้นหา/กรอง/ขอบเขตแทนโดยไม่แสดงผลจำลอง มือถือในโหมดเปรียบเทียบกด “เลือกโครงการ” ด้านล่างเพื่อเปิด/พับรายการ ส่วนแผนที่เดียวกดชื่อโครงการเหนือ sheet เพื่อพับและดูแผนที่ได้เต็มขึ้น
